Notes

• MockAPI creates id by itself ("1", "2", …). Use those ids in productId, orderId, sellerId etc. – not the "P101" style ids from the PDF.
• Faker only gives random words, so fields like status/role/reason will contain random text at first. Run await API.seedRemaining() once (browser console) to insert proper demo rows into the 6 new collections, and delete the random ones in the MockAPI dashboard.
• If a Value name is not accepted by your MockAPI version, use the grey alternative under it (newer Faker names).
• Your support resource is called tickets (not supportTickets) – the api.js file already uses that name; rename it there if yours differs.
