Full neutral, tint (-100) and pressed (-600/700/900) steps are in design-tokens.css. Use --color-cta-500 for the main "Add to Cart" action, --color-cta2-500 for "Buy Now", --color-primary-700 for the navbar — never a raw hex value in component code.

Typography

Both headings and body use a plain system font stack (Segoe UI / Roboto / Arial fallbacks) — closest free match to Amazon Ember, and needs no font download.

--fs-4xl / 48pxHero heading
--fs-2xl / 30pxPage heading
--fs-lg / 20pxCard title
--fs-base / 16pxBody copy — product descriptions, form text
--fs-sm / 14pxSecondary text — labels, meta, captions
--fs-xs / 12pxFine print — timestamps, badges

Utility classes are generated from this scale: .mt-4, .mb-6, .px-2, .py-8 … for margin/padding on all sides, top, bottom, and inline/block axes.

Responsive breakpoints

NameMin-widthTypical device
sm576pxLarge phones
md768pxTablets
lg992pxSmall laptops
xl1200pxDesktops

Mobile-first: base styles are for phones, each breakpoint adds/overrides with @media (min-width: …). These match Bootstrap's own breakpoints, so the two systems won't fight if a page uses both.
